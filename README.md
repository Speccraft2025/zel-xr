# Zel XR official landing page

This self-contained static site is deliberately separate from the existing Kidspark collaboration site. It describes current browser-based AR and interactive-media services, and labels hardware as future exploration rather than an available product.

## Local preview

From this directory, run:

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080`.

## Before publishing

Replace the project-enquiry email address in `index.html` only if `hello@zelxr.com` is not your live inbox. Publish this folder as a new, separate site; do not deploy it over the Kidspark collaboration URL.
